#MINDORA:- A Modern Social Media Platform

MINDORA is full-stack social media application designed for authentic connections, real-time interactions, and seamless content sharing.

Live Demo: https://mindora-79afa.web.app

💻Repository:github.com/florakhn305/MINDORA-APP

###✨Key Features
-🔐Secure Authentication(Firebase Auth)
-📃Create, Edit, Delete, Posts with images
-💖Like, Comment & Share System
-🎮1v1 war battle game for fun interaction
-👤User Profile & Follow System
-📰Personalized Feed
-🔔Real-time Update (Firestore)
-📱Fully Responsive design

###🛠️Tech stack
Fronted: React.js, TypeScript, Tailwind CSS
Backend & Database: Firebase( Firestore, Authentication, Hosting)
Deployment: Firebase Hosting & Github
